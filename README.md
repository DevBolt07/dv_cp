# IPL Performance Analytics

This repository contains a data visualization and statistical analysis project on IPL 2008--2019 ball-by-ball data.

## Contents

- `Module1_Preprocessing.ipynb`: data cleaning, normalization, feature engineering, and export pipeline
- `Module2_Batting.ipynb`: batting-focused descriptive analysis and visualizations
- `Module3_Bowling.ipynb`: bowling-focused descriptive analysis and visualizations
- `ipl_performance_paper.tex`: IEEE-style research paper draft
- cleaned datasets and summary tables used across the notebooks

## Datasets

- `matches.csv`
- `deliveries.csv`
- `matches_clean.csv`
- `deliveries_clean.csv`
- `legal_deliveries.csv`
- `player_stats.csv`
- `bowler_stats.csv`
